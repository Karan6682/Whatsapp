# WhatsApp Demo

A lightweight, single-file WhatsApp Web UI demo built with plain HTML, CSS, and JavaScript — no dependencies required.

## Features

- **Sidebar** with a scrollable contact/chat list and search filter
- **Chat window** with speech-bubble messages (incoming & outgoing)
- **Send messages** by pressing <kbd>Enter</kbd> or clicking the send button
- **Auto-reply** simulates the other person responding
- Faithful dark-theme recreation of WhatsApp Web's colour palette

## Usage

Simply open `index.html` in any modern browser — no build step or server needed.

```bash
open index.html      # macOS
xdg-open index.html  # Linux
start index.html     # Windows
```
